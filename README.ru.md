# LowCalculator

[English](README.md) | **Русский**

Сверхлёгкий калькулятор для Android 4.0.3 – 4.4.4 (API 15–19). Весь интерфейс (экран и кнопки) рисуется программно на `Canvas` в стиле Holo Dark, без XML-разметки. Цель — APK меньше 20 КБ.

- Пакет: `com.m929.lowcalculator`
- Чистая Java, без Kotlin, androidx и сторонних библиотек
- Один файл с логикой и отрисовкой: `app/src/main/java/com/m929/lowcalculator/MainActivity.java`
- Название приложения локализовано (`res/values-*/strings.xml`)

## Раскладка

```
[C] [√] [^] [÷]
[7] [8] [9] [×]
[4] [5] [6] [−]
[1] [2] [3] [+]
[0] [.] [  =  ]
```

Нажатия клавиш сопровождаются стандартным системным звуком (учитывается настройка «Звук нажатия»). Деление на ноль даёт `Error`, в числе допускается только одна точка, цепочки операций считаются слева направо.

## Сборка

Нужны JDK 17 и Android SDK. Откройте проект в Android Studio или выполните:

```
gradle wrapper      # один раз, создаст gradlew
./gradlew assembleRelease
```

APK: `app/build/outputs/apk/release/`. Для проверки размера собирайте именно **release** (R8 + shrinkResources); debug-сборка заметно больше. Release подписывается отладочным ключом, для публикации подставьте свой. Подпись только v1, так как Android 4.x другие схемы не понимает.

GitHub Actions (`.github/workflows/build.yml`) собирает release-APK при каждом push и прикладывает его как артефакт.
